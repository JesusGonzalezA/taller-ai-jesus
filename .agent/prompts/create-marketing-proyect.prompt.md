## Objetivo
Vamos a añadir una nueva feature. Quiero convertir mi proyecto en una aplicación para marketing.

## Funcionalidades
- Definir información de la empresa, briefing, estilo de comunicación, redes, etc
- Tener un input para subir un transcript de teams, un archivo, etc. Podré pedirle que me haga a partir de esto una campaña de marketing. La idea es que, dadas las redes preconfiguradas en la empresa, el estilo de cada una, el briefing general y el contenido de estos archivos genere una estrategia de marketing. Debe de generar un calendario tipo, fotos para cada publicación, copy, etc.
- Dada una estrategia generada, debo de poder iterar con cada artefacto generado y reordenar las publicaciones en el calendario
- Debo de poder exportar cada publicación fácilmente
